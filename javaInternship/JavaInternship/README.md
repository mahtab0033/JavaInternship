# Java Internship - Phase 1

## Project
Hello World - Java setup verification project.

## Requirements
- Java Development Kit (JDK)
- VS Code or IntelliJ IDEA (optional)

## How to run

Open a terminal in the project folder and run:

```bash
javac src/Main.java
java -cp src Main
```

## Expected output

```text
Hello World
My Java Internship has started!
```

## Purpose
This project verifies that the Java compiler (`javac`) and Java runtime (`java`) are installed and working correctly.
